## 🌟 Overview
**Humsafar Rishta Centre** is a high-security, dignified matrimonial platform catering to educated professionals (Doctors, Engineers, Businessmen) as well as candidates affiliated with religious seminaries (**Deeni Madaris / Dars-e-Nizami / Aalima / Huffaz**) and Tablighi/practicing religious mindsets across Pakistan and overseas.

## 🛡️ Key Features & Security Architecture
1. **Fee-Gate / Paywall Protection (فیس ادا کر کے رشتہ دیکھیں)**:
   - Preview of candidate basics (ID, age, height, qualification, profession, city) is public.
   - Candidate full name, direct parent phone number, and exact home address are locked behind a secure fee gate.
   - Payment plans:
     - Single Rishta Pass: Rs. 500
     - Silver Plan (15 Rishtas): Rs. 7,500
     - Gold VIP Unlimited: Rs. 15,000
   - Instant unlock with Access PIN (e.g., `VIP-786`) or WhatsApp payment receipt verification.
2. **Admin Control Center**:
   - Master password protected with brute-force lockout after 5 failed attempts.
   - Custom password update tool directly inside the panel.
   - Direct "+ Add New Rishta" database insertion form.
   - Client Access PIN generator with custom code allocation.
   - Real-time cryptographic audit log viewer backed by Python 3.12.
3. **100% Family Privacy Shield**:
   - Photographs are never displayed publicly without mutual parental consent.
   - Watermarked confidential viewer preventing unauthorized scraping.

## 📦 Local Installation & Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Node.js Backend API
```bash
node backend/server.js
```
*Backend runs on `http://localhost:5000`*

### 3. Start Frontend Development Server
```bash
npm run dev
```
*Frontend runs on `http://localhost:5173`*

### 4. Run Python Security Audit
```bash
python backend/security_engine.py audit
```
